# Instrument Boundaries: What a Small-Model Humor Meter Can and Cannot Read

*HumorVibes / Jestry research note, 2026-07-24. Every number below traces to a receipt file in this repo; paths are given inline. Nothing here is an estimate.*

## Summary

We measure jokes as controlled prediction error with a cheap permitted repair, using teacher-forced negative log likelihood from small Gemma models. Building and hardening that instrument produced five findings that are more general than this project: a transport-level copy attractor in raw-mode frame conditioning, a censoring failure that makes top-K logprob APIs unusable as humor meters, an EOS boundary artifact that silently deletes logprobs, a format boundary that limits which text shapes the meter can read at all, and a corrupt-weights failure in which a model returned NaN for every logit while a receipt still called the result measured. Each was caught by a calibration or adversarial receipt, not by intuition. Sections 7 and 8 add an executed follow-up to the format boundary and the dataset the whole apparatus now exports.

## 1. The certified instrument

`gemma2_full_nll.py` runs gemma-2-2b-it (public bartowski Q4_K_M GGUF) under llama.cpp with `logits_all=True`, so continuation NLL is exact over the full vocabulary. Calibration against reference jokes and controls passed: jokes show resolution R of 0.08 / 0.121 / 0.444 while both controls sit at exactly 0, with the derived acceptance region S in [1.91, 8.07], R floor 0.04, E floor 0.0027. Receipt: `jestry_out/gemma2_full_nll_calibration.json` (`certified: true`). The same receipt embeds its own adversarial scope: a crafted frame can walk a boring line into the acceptance region (R 0.215 on the "boring" control), which is why frame hints only reach the oracle from trusted provenance. That scope note is a condition of certification, not a footnote.

The pinned Kaggle regime reproduces exactly on this instrument: the speed-bumps reference case reads 3.188 in the competition notebook (transformers, GPU; wave2_publication.json), 3.19 locally on llama.cpp Q4 (gemma2_full_nll_calibration.json), and 3.200 on llama.cpp Q8 (gemma2_full_nll_quant_check.json) — a spread of ≤ 0.012 nats around the pinned 3.19, four instruments inside one band rather than one identical number. Receipted in the wrapper kernel run.

A fourth instrument was added tonight to test whether that agreement is an artifact of low-precision weights. Re-running the same five reference cases on a Q8_0 requantization, four times the precision of the certified Q4_K_M, leaves the acceptance behavior identical: all three jokes inside the region, both controls outside, largest S movement across the whole reference set 0.261 nats and largest R movement 0.006. The pinned case moves from 3.190 to 3.200, so S = 3.19 is not a quantization artifact. The Q4 arm of the same run reproduces the certified receipt at exactly zero drift on all five cases, which makes it a reproducibility check on the calibration as well as a robustness check on the quantization. Receipt: `jestry_out/gemma2_full_nll_quant_check.json`.

## 2. The honest failure: top-K readouts cannot be humor meters

The Ollama transport exposes at most the top 20 logprobs per position. Calibrating the gemma4 forced-NLL readout against the same reference set FAILED separation: reference jokes measured R of 0 / 0.306 / 0 while the boring control measured R = 0.726, an inversion of the property the meter exists to detect. Receipt: `jestry_out/gemma4_calibration.json` (`certified: false`, 117 API calls, 0 instrument errors). The mechanism is censoring: when the true continuation token falls outside the top K, its NLL is a lower bound clipped toward the K-th mass, and resolution, which is a difference of means, inherits the clip asymmetrically. Consequence in the layer: this instrument never gates acceptance; it remains a generator, frame writer, and persona judge only.

## 3. The copy attractor

With a ground-truth frame hint placed after the setup (suffix layout), gemma4 in raw mode parrots the hint's own n-gram continuation instead of predicting the punchline: at "...getting over" the frame's continuation token " the" measured 0.00 nats while every alternative sat at 8.65 to 10.33 nats; moving the same hint before the setup (prefix layout) restored the true continuation " it" to 0.03 nats. Receipt: `jestry_out/instrument_sweep.jsonl`, entry ts 2026-07-24T10:20:54. Mitigation shipped in the provider: suffix hint layouts are rewritten to prefix, decoy null included, guarded to genuine hint shapes of 25 characters or more. The general lesson: conditioning text placed between context and continuation is not neutral scaffolding for an autoregressive scorer; it is a copy target.

## 4. The EOS boundary artifact

gemma4:e2b emits EOS at sentence-plus-newline prompt boundaries in raw mode, and the transport then omits the logprobs entry for that position entirely: "capital of France is" returns logprobs, a canonical setup plus newline does not, at K = 10 and K = 20 alike. Stepwise teacher forcing is therefore not viable on e2b over this transport, and the same mechanism explains the 8B model's intermittent missing-logprobs hiccups at framed-context boundaries. Receipt: `jestry_out/instrument_sweep.jsonl`, entry ts 2026-07-24T00:07:05. This is worth knowing before anyone builds an evaluation harness on raw-mode logprobs from an Ollama-served Gemma.

## 5. The format boundary

Two pinned results pointed the same direction. The source-pinned ablation court on Humicroedit-style edited headlines completed 200 of 200 measurements and found the full S/R/E/B score does not track human funniness there: rho = 0.033, 95% CI [-0.126, 0.207] (receipts under `research_out/kaggle/humorvibes-ablation-court/`). The direct Humicroedit validation measured laugh_score spearman 0.115 at n = 180 (`research_out/kaggle/humorvibes-validate-ratings/validation_results.json`). The working hypothesis after the ablation was that the instrument only reads jokes whose prediction-error site sits at an explicit setup/punchline seam, and headlines have no such seam: the generic splitter falls through to a blind 70 percent word cut, so the measured "punchline" usually straddles or misses the edited word that carries the joke.

Humicroedit makes this hypothesis directly testable, because each item records exactly where the edit sits. Tonight's controlled experiment re-measures the same sampled items on the certified instrument under three split conditions with one shared, deterministic, leak-safe frame hint: the pinned generic split, an edit-anchored canonical split (setup ends where the edited word begins), and a fixed 40 percent control cut so that "canonical wins" cannot be explained by "any different split wins". Design, code, and receipts: `canonicalize_format.py`, `jestry_out/format_boundary_experiment.json`, per-measurement audit trail in `jestry_out/format_boundary_items.jsonl`. Results are in section 7 below.

## 6. The frame channel reads across languages

The been-done index labels items with one-sentence frames (comic engine descriptions) and embeds them separately from surface text. Deliberately constructed frame families planted across languages rank as a family under hinted probes with zero surface-text match: the pit-digger family (Hungarian, Serbian, German), wasted-refinement (Chinese, Japanese, Hindi), and experts-slip (Tamil, probe similarity 0.603). Receipt: `jestry_out/precedent_probes.json`, which also pins the cross-lingual surface results (Korean 0.721 and Japanese 0.702 for the falling-monkey paraphrase, Yiddish 0.849 for "Man plans and God laughs"). As of that receipt the index held 230 labeled frames from 150 judge calls with zero failures; the index itself has since grown to 23,779 items after tonight's French and Italian wikiquote harvest (`corpora/harvest_wikiquote_citation_20260724.jsonl`, receipts in `jestry_out/harvest_receipts.jsonl`).

## 7. Format-boundary experiment results

The run completed on 83 items (one of the 84 sampled rows had a degenerate edit position and was dropped before measurement), 249 measurements total, zero instrument errors. Receipt: `jestry_out/format_boundary_experiment.json`.

| condition | laugh vs grade | S vs grade | R vs grade | mean R | items with R > 0 |
|---|---|---|---|---|---|
| generic (pinned splitter) | -0.025 | 0.112 | -0.047 | 0.050 | 19.3% |
| canonical (edit-anchored) | -0.092 | 0.163 | 0.030 | 0.122 | 31.3% |
| control (fixed 40% cut) | -0.103 | 0.183 | -0.052 | 0.039 | 20.5% |

**Correction, 2026-07-25.** The correlations in this table were recomputed after our own adversarial audit found that the ranking function broke ties by array position, which silently correlates a low-cardinality column with row order. Several values moved and three changed sign (generic R read +0.056 against a true -0.047). The statistic now uses tied-value midranks, verified against scipy. The engagement fractions, the measured S/R/E values, and the conclusion are unaffected: no split condition predicts human funniness, and every correlation remains inside noise. The receipt carries a `correction_2026_07_25` block listing every changed value.

Correlations are spearman against the human mean grade, with permutation p values over 2000 seeded label shuffles. E is omitted from the table because the shared hint is exactly ten words for every item, making E an exact rescaling of R with identical correlations; that identity in the receipt is a property of the design, not a bug.

**The mechanistic claim survives.** Anchoring the split at the edited word roughly doubles how often the instrument finds any resolution at all, from 19.3% of items to 31.3%, and lifts mean R from 0.050 to 0.122. The control condition is what makes this interpretable: it is also a different split, also not the pinned one, and it does not move R engagement (20.5%, mean 0.039). So the lift is specific to putting the measurement window on the joke's actual seam, not to disturbing the split.

**The predictive claim does not survive.** None of that buys any ability to predict human funniness. Every laugh-score correlation is statistically indistinguishable from zero, and the canonical condition's point estimate is slightly negative. The instrument engages more, and still does not track the grade.

This is a sharper and more falsifying result than the hypothesis it was built to test. The prior story after the ablation court was that headlines fail because the splitter mangles them, which implied a fix: canonicalize the format and the correlation should appear. It did not appear. For one-word headline edits, what human raters grade as funny is not what resolution measures, even when resolution is measured at the right place. Two readings remain open and are distinguishable by future work: either Humicroedit's humor is carried by mechanisms other than affordable reframing (a substitution can be funny by incongruity alone, with no repair to find), or a 2B-parameter instrument cannot resolve the effect at this sample size. The honest position today is that the format boundary is not a splitting artifact.

Two caveats belong with these numbers. First, this experiment holds the frame hint fixed and deterministic across conditions to isolate the split variable, while the pinned validation run let the model generate a frame per item; the pinned spearman of 0.115 is therefore context rather than a fourth arm, and the comparison that is controlled here is generic versus canonical versus control. Second, mild positive S trends appear in all three conditions (0.117, 0.170, 0.193), the largest in the control condition at p = 0.076, which does not survive any correction for the twelve comparisons in the table and is reported here as a trend to re-test, not a finding.

## 8. The genome as a portable dataset

Everything above is measured on supply that now exports as a dataset rather than living inside the project's own index: comedy mechanisms and format specs as structured primitives, every indexed item with source, license and language, the Gemma-labeled frame subset, the rows carrying real teacher-forced signals, and both embedding channels as aligned matrices. Generated by `comedy_primitives_dataset.py` into `dataset_out/` with a card and a manifest of digests.

The dual-channel design is the part worth reusing elsewhere. Embedding the comic frame separately from the surface wording is what allows retrieval on the mechanism rather than the words: querying with the Korean "even monkeys fall from trees" vector returns the Japanese equivalent at 0.892, then the Tamil "even an elephant's foot slips" at 0.627, which shares no surface vocabulary and not even the animal. A single-channel index cannot express that relation. The export was checked by loading it with nothing but numpy, the way an outside user would.

## 9. A corrupt-weights honesty bug, found by accident

While preparing the quantization probe, a resumed download produced a GGUF of 2,834,392,928 bytes against the published 2,784,495,456, sha256 `c6c8c1e8...` against the published LFS oid `2d448a9a...`. llama.cpp loaded that file and evaluated it without raising a single error, and every logit came back NaN. The NaN propagated through the signal computation into a receipt that still reported `measured: true` with `S: NaN` and `R: 0.0`: a receipt claiming a measurement that never happened, which is exactly the failure mode this project's receipt discipline exists to prevent.

Fixed in `gemma2_full_nll.py`: non-finite NLLs are now counted as instrument errors and degrade to `measured: false`, so the invariant that "measured means measured" holds even against corrupt weights. Receipt: `jestry_out/instrument_sweep.jsonl`, latest entry. The operational discipline that follows is to verify a GGUF's sha256 against the published object before trusting any receipt derived from it, and never to resume a partial GGUF download with `curl -C -`. The certified Q4_K_M calibration is unaffected; its values are finite and still reproduce S = 3.19.

## 10. Native format: the decisive follow-up

Section 7 leaves one reading of the format boundary untested. If headline edits are simply the wrong shape, the instrument should do better where the shape is native. r/Jokes posts are exactly that: the title is the setup and the body is the punchline, so no splitter heuristic is involved at all. `native_format_probe.py` measures that population on the certified instrument in two arms, because the available human signal there is weak.

The clean arm needs no rating. Genuine pairs are measured against shuffled pairs in which a punchline is swapped in from a different setup, and the theory's claim is directly testable: a genuine pair should resolve under its frame, a mismatched one should not survive the decoy null. That is reported as a rank-sum AUC over R, alongside how often R clears zero in each group. The exploratory arm correlates the signals with log2(1 + upvotes), and upvotes are a popularity proxy confounded by timing, subreddit dynamics and visibility, so a null there is weak evidence while a positive would be strong. Supply is screened for slurs, abuse and identity-topic material before anything reaches the instrument or a receipt, since these rows ship in a public dataset.

**The result is negative, and it points somewhere specific.** Across 30 pairs and 60 measurements with zero instrument errors, R does not separate genuine jokes from shuffled ones. It runs backwards: AUC 0.406, mean R 0.142 for genuine against 0.273 for shuffled, with R clearing zero on 56.7% of genuine pairs against 66.7% of shuffled ones. The composite laugh score is exactly at chance (AUC 0.497). The exploratory upvote arm is null as expected and carries little weight either way (laugh -0.017, R -0.044, S -0.191 against log2 upvotes).

The mechanism is the interesting part, and it is not a contradiction of the certified calibration. In that calibration the frames were **given**: ground-truth frames for the reference jokes, and the controls got no frame at all, which is why both controls measured exactly zero. In this probe every frame was **written by the model, per item, including for the deliberately mismatched pairs**. Asked to explain a punchline that does not belong to its setup, the model does not refuse. It confabulates a bridge, and a bridge built to reconcile two unrelated ideas is more elaborate and more specific than the obvious frame a genuine joke needs. That tailored confabulation collapses the punchline's surprisal more than the honest frame does, and the null control cannot absorb it, because the null is a single fixed generic decoy rather than a per-item confabulation. The leak guard removes frames that quote the punchline; it does not remove frames that merely reason hard.

The strongest-scoring shuffled pair in the run shows it plainly. The setup "A doctor tells a woman she can no longer touch anything alcoholic" was given the punchline "If you beat your fish, it dies!", taken from a different joke. The model's frame reads "The doctor is implying the woman's hands are too shaky or weak to handle alcohol, and the punchline is a literal, unrelated...", and that pairing measured R = 1.426, an order of magnitude above the mean genuine pair. The frame explicitly says the punchline is unrelated and still collapses the surprisal, because what the measurement rewards is conditioning text that makes the tokens cheaper, not an explanation that is true.

So the instrument is trustworthy about resolution exactly when the frame's provenance is trustworthy, and unreliable when the frame is invented per item by the model being measured. That is precisely the rule this project already enforces: the frame-provenance trust gate added after an adversarial audit, which permits only curated or traditional sources to supply a frame that reaches the acceptance oracle (section 1's `adversarial_scope`). Before tonight that gate rested on a single crafted-frame probe. It now has a 30-pair measurement behind it, and the honest summary is stronger than the gate's original justification: model-written frames do not merely admit a bad joke occasionally, they invert the ordering on a population.

Two limits on the claim. The sample is 30 pairs from one subreddit under a conservative content screen, so the effect size is soft even though the direction is clear. And this says nothing about the certified regime, which measures with given frames and is unaffected; the Q4 and Q8 reference runs in section 1 still separate jokes from controls perfectly. Full protocol and every measurement: `jestry_out/native_format_probe.json` and `jestry_out/native_format_items.jsonl`, with the rows folded into the exported `measured_signals.jsonl`.

## 11. What follows from this

The instrument stack now has a clean division of labor with receipts at every joint: exact full-vocabulary NLL for measurement, generation and judging delegated to the larger model, frames only from trusted provenance, and acceptance gated by a certified calibration that carries its own adversarial scope and is now known to survive a fourfold change in weight precision. The open levers, in order of expected value: extend certification to a second model family, since every robustness result so far lives inside one; push the native-format line further, because it is the only arm where a clean separation signal is available without depending on a noisy human proxy; scale frame labeling, which covers 270 of 23,779 items and is the sparse half of the dual-channel index that makes cross-lingual retrieval work; and collect live audience outcomes, because model judgment is explicitly not human laughter and every acceptance receipt in this repo says so on its face.
